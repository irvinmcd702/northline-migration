# Northline Industrial Supply — static site

Astro site migrated from WordPress. Demo project, fictional company.
This file is written for the people who maintain the site: follow it literally.

## Commands

    npm install
    npm run dev        # http://localhost:4321
    npm run build      # static output in dist/
    npm test           # after build: every old WordPress URL resolves, every page has a title

## Where things live

| What | File |
|---|---|
| Pages (About, Services, Contact, …) | `src/content/pages/<slug>.md` |
| Products | `src/content/products/<slug>.md` |
| Product categories | `src/data/product-categories.json` |
| Used equipment | `src/content/inventory/<slug>.md` |
| Projects | `src/content/projects/<slug>.md` |
| Blog posts | `src/content/posts/<slug>.md` |
| Images | `src/assets/media/` (optimised at build time) |
| PDFs | `public/media/` (served as-is) |
| Redirects | `public/_redirects` |
| Old `?p=<id>` links | `src/data/wp-ids.json` |
| Field rules for every type | `src/content.config.ts` |

The URL of an entry is its file name: `src/content/products/gear-pump-gp-15.md`
→ `/products/gear-pump-gp-15/`. Renaming a file changes its URL — add a
redirect when you do (see below).

## Common tasks

**Add a product.** Copy an existing file in `src/content/products/`, rename it
to the new slug, and edit the front matter. Required fields: `title`, `sku`,
`category` (a slug from `src/data/product-categories.json`), `excerpt`,
`specs` (list of `{"key": …, "value": …}`), `image` (a file in
`src/assets/media/`, written as `../../assets/media/<file>`), `datasheet`
(`/media/<file>.pdf` or `null`). `wpId` must be unique; for new entries use
any number above 100000. `oldUrl` is the entry's own URL.

**Mark used equipment as sold.** In `src/content/inventory/<slug>.md` set
`status: "sold"`. Allowed values: `available`, `reserved`, `sold`.

**Edit text.** Edit the Markdown below the front matter. Blocks in
`<div class="wp-block-columns">` and embeds are HTML kept from WordPress;
edit them as HTML.

**Add a redirect.** Add a line `/old-path/ /new-path/ 301` to
`public/_redirects`, above the wildcard rules (Cloudflare uses the first
match).

**Check before you push.** `npm run build && npm test` must pass.

## Forms

The quote form posts to `functions/api/quote.js` (a Cloudflare Pages
Function). It checks Cloudflare Turnstile and forwards the request to a
webhook; nothing is stored on the site. Settings are Cloudflare environment
variables: `TURNSTILE_SECRET` and, optionally, `WEBHOOK_URL` (never commit them).
Without `WEBHOOK_URL` the form runs in demo mode: it checks Turnstile and
shows the thanks page, but sends nothing.

## Content source

`src/content/`, `src/data/`, media and `_redirects` were generated by
`../exporter` from the WordPress site in `../wp-source`. After the migration
the Markdown files are the source of truth; re-running the exporter
overwrites manual edits.
